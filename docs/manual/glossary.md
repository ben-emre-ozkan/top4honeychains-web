# Glossary of the user manuals

One row per term of the manuals, one column per language. A text from the application's own resource files or reference translations (what the screen shows) is written as it is. A text the translators chose is marked **(?)** where they were not sure that a native professional reader would use it; the partners are asked to confirm or correct those. Where the interface itself shows a text that looks wrong or is still in English, it is marked **(?)** too, and the manual uses it as the screen shows it.

Unsure terms: tr 20, es 21, pl 45, lv 26.
