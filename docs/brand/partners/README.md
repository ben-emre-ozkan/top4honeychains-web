# Consortium and programme logos

Copies for the user manual cover (D-77), made from the files the project supplied (`Partner Logos`). The originals were not changed. Each copy is trimmed to its content with a small even margin, kept on a transparent or white background, and scaled to a height of 240 px (never enlarged beyond the original pixels). The cover prints them 10 mm high.
