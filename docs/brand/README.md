# TOP4HoneyChains brand kit

Logo designed in October 2026: a bee whose wings open behind three interlocked hexagon links (the value chain and the honeycomb), with a turquoise head. All files are vector except the icons; text in the logos is converted to outlines, so no font is needed to display them.

## Files

| File | Use |
|---|---|
| `top4-mark.svg` | Detailed mark (honeycomb cells and veins in the wings). Use at 48 px and larger. |
| `top4-mark-small.svg` | Simplified mark for sizes under 48 px (favicon, compact menus). |
| `top4-mark-mono.svg` | One-colour caramel version for stamps, PDFs and single-colour print. |
| `top4-mark-square.svg`, `top4-mark-small-square.svg` | Same marks on a square 200×200 canvas, for icon generation. |
| `top4-logo-w3.svg` | Mark + W3 wordmark (TOP4HONEYCHAINS with hexagon O's). Default horizontal logo: top bar, landing header, sign-in, documents. |
| `top4-logo-w2.svg` | Mark + W2 wordmark (TOP4 over HONEY ◆ CHAINS). Compact horizontal logo. |
| `top4-logo-stacked.svg` | Mark above W2. Square spaces, social media, posters, cover pages. |
| `top4-wordmark-w3.svg`, `top4-wordmark-w2.svg` | Wordmarks without the mark. |
| `favicon.ico` (16/32/48), `favicon-32.png` | Browser favicon (simplified mark). |
| `apple-touch-icon.png` (180, white) | iOS home screen. |
| `icon-192.png`, `icon-512.png` | Web app manifest icons. |
| `icon-maskable-512.png` | Manifest icon with `"purpose": "maskable"` (cream background, safe zone respected). |
| `brand-preview.png` | Overview of all logo files. |

## Rules

- Do not recolour, stretch, rotate or add effects. Do not redraw the mark in CSS.
- Clear space around the logo: at least the width of the bee's head on every side.
- Use on white or the light honey-foam backgrounds only (the brand has no dark backgrounds).
- Logos are exempt from WCAG text-contrast rules (logotypes); keep the colours as they are.
- Detailed mark at 48 px and above, simplified mark below 48 px.
